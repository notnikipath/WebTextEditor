# Task_2 - Web Text Editor

Учебный проект простого текстового редактора в веб-формате с запуском в Docker.

## Реализованные базовые требования

- GUI: главное окно с областью ввода текста, меню (`Файл`, `Правка`, `Справка`), панель инструментов, строка состояния.
- Поддержка изменения размера окна (адаптивная верстка для desktop/mobile).
- Создание нового файла.
- Открытие файлов `.txt` и `.rtf`.
- Сохранение файла (`Сохранить`, `Сохранить как...`).
- Редактирование: копирование, вставка, вырезание, отмена.
- Поиск текста в открытом документе (вперед/назад + счётчик совпадений).
- Подсчёт слов, символов, строк.

## Дополнительные улучшения

- Автосохранение черновика (каждые 30 секунд, в `localStorage`).
- Тёмная и светлая тема.
- Изменение шрифта и размера текста.
- Markdown с предпросмотром.
- Горячие клавиши (`Ctrl+N`, `Ctrl+O`, `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+F`, `Ctrl+Z`, `Ctrl+P`).
- Печать/экспорт в PDF через системный диалог браузера.

## Быстрый запуск в Docker

```bash
docker compose up --build -d
```

Открыть в браузере:

- http://localhost:8080

Остановка:

```bash
docker compose down
```

## Локальный запуск без Docker

1. Запустить простой сервер:

```bash
cd Task_2
python -m http.server 18090
```

2. Открыть:

- http://localhost:18090/src/

Примечание: для полного режима сохранения в исходный файл (File System Access API) запуск через `http://localhost` предпочтительнее, чем `file://`.

## Горячие клавиши

- `Ctrl+N` - новый файл
- `Ctrl+O` - открыть
- `Ctrl+S` - сохранить
- `Ctrl+Shift+S` - сохранить как
- `Ctrl+F` - поиск
- `Ctrl+Z` - отмена
- `Ctrl+P` - печать / PDF
