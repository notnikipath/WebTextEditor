О программе

Web Text Editor (Task 2) - учебный текстовый редактор с поддержкой .txt/.rtf, поиском, автосохранением и Markdown-preview.

Горячие клавиши

  • Ctrl+N - Новый
  • Ctrl+O - Открыть
  • Ctrl+S - Сохранить
  • Ctrl+Shift+S - Сохранить как
  • Ctrl+P - Печать / экспорт в PDF
  • Ctrl+F - Найти
  • Ctrl+Z - Отменить
  • Ctrl+C / Ctrl+X / Ctrl+V - Копировать / Вырезать / Вставить
