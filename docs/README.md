# Отчёт по проекту Task_2

## 1. Описание реализованных функций

### Обязательная часть

1. Интерфейс:
- Главное окно с текстовым полем (`textarea`).
- Меню: `Файл`, `Правка`, `Справка`.
- Панель инструментов: `Новый`, `Открыть`, `Сохранить`, `Копировать`, `Вставить`, `Вырезать`.
- Строка состояния: имя файла, счётчик слов/символов/строк, статус автосохранения, текущее время.
- Адаптивная верстка для изменения размеров окна.

2. Функциональность:
- Новый файл.
- Открытие `.txt` и `.rtf`.
- Сохранение (`Сохранить`) и `Сохранить как...`.
- Редактирование: копирование, вставка, вырезание, отмена.
- Поиск текста (следующее/предыдущее совпадение).
- Подсчёт слов и символов (и строк).

### Дополнительные возможности

1. Автосохранение по интервалу (30 секунд).
2. Тёмная/светлая тема.
3. Изменение шрифта и размера текста.
4. Markdown-предпросмотр.
5. Горячие клавиши для действий.
6. Печать/экспорт в PDF через браузер.

## 2. Скриншоты интерфейса

Рекомендуется сделать минимум 3 скриншота после запуска:

1. Основной экран редактора.
2. Работа поиска по тексту.
3. Тёмная тема + markdown preview.

(Файлы скриншотов можно положить в `docs/screenshots/`.)

## 3. Инструкция по сборке и запуску

### Docker

```bash
cd Task_2
docker compose up --build -d
```

Адрес:

- `http://localhost:8080`

Остановка:

```bash
docker compose down
```

### Локальный запуск

```bash
cd Task_2
python -m http.server 18090
```

Открыть:

- `http://localhost:18090/src/`
